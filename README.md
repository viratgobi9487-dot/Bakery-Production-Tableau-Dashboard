
# Bakery Production Analysis – Tableau Dashboard

## Project Overview
This project analyzes bakery production and sales data using Tableau. The dashboard helps understand production performance, sales, revenue, product performance, and customer ratings.

## Tools Used
- Tableau
- Microsoft Excel

## Dataset
The dataset contains 2,000 records related to bakery production and sales.

## Project Files
- `Bakery_Production_Dashboard.twbx` – Tableau packaged workbook
- `Bakery_Production_Tableau_Dataset_2000(2).xlsx` – Excel dataset

## Key Objectives
- Analyze total sales and revenue
- Monitor production performance
- Compare product-wise sales
- Analyze wastage and shift-wise sales
- Understand customer ratings and product quality

## How to Open
1. Download the `.twbx` file from this repository.
2. Open Tableau Desktop.
3. Open the downloaded packaged workbook.
4. Explore the dashboard and interact with its filters.
